Compare
Compare switches between two ways of reading each team's season.
  • Weighted: every past game counts according to how much it looks like this matchup: similar opponents, recent weeks, same setting and the same key players. The strength of each factor is set by the Weighting sliders.
  • Unweighted: every game counts the same (by plays), like a plain season average. This is the equal-weight model.
  • Both shows them side by side so you can see what the weighting changes.
This choice changes the score projection and the radar charts. Weighted is drawn as solid, filled shapes; unweighted as dashed outlines. Both projections use the same points model and opponent adjustment; only the game weights differ.
